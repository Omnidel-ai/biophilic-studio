# Biophilic Studio

Promotional site for **Biophilic Studio** at Shop No. 127, Downtown Mall, New Town, Kolkata — a karmyog Vātika space for podcasts, meetings, and content creation.

**Live:** https://biophilic-studio.vercel.app/

## Preview locally

```bash
npx serve .
```

Open http://localhost:3000 (or the port shown).

## Structure

- `index.html` — main page (EN/BN toggle, Google Form embed)
- `css/` — compiled Tailwind + UX/readability fixes + design refresh
- `js/main.js` — nav, lightbox, i18n
- `styles.css` / `script.js` — compatibility shims (kept so older links still resolve)
- `images/` — studio photography + Vatika logo
